# dashboard/

The 4 PNGs here are **matplotlib-generated dashboard previews**, not actual
Power BI screenshots — every number on them is real (pulled straight from
`data/processed/*.csv`), but the rendering engine is Python. Power BI
Desktop is Windows-only and unavailable in the environment this project was
built in, so a real `.pbix` export wasn't possible; see
[`../powerbi/README.md`](../powerbi/README.md) for what's included instead
(a `.pbip` project + full build guide).

Regenerated by [`generate_previews.py`](generate_previews.py) in this same
folder — if you change the underlying data, re-run it (`cd dashboard &&
python3 generate_previews.py`) to refresh these.

If you build the real report in Power BI Desktop, overwrite these files with
your own screenshots (same filenames) so `README.md`'s embeds show the real
thing:

- `01_executive_overview.png`
- `02_demand_operations.png`
- `03_driver_performance.png`
- `04_customer_cancellation_risk.png`
